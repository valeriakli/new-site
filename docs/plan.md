# План запуска

Обсуждение с Олей, ноябрь 2026. Отмечайте выполненное `[x]`.

## Что решено
- Отдельный сайт с **отдельной админкой WordPress**. Логику берём с profcosmetica (WooCommerce, оплата, доставка, сниппеты). Страницы копируем и переделываем, тексты — с помощью ИИ.
- **Только Беларусь.** РФ и Грузия не нужны.
- **Новое юрлицо** (переписка 12.11.2026). С profcosmetica берём только структуру и логику. Свой кабинет bePaid, свои реквизиты, оферта и политика конфиденциальности.
- Клиентов, заказы и подписчиков profcosmetica не переносить: это персональные данные другого юрлица.
- Бренды и товары с profcosmetica можно перенести (каких — решает Оля).
- Срок — примерно 1–1,5 месяца. Самое долгое — дизайн, тексты и bePaid (зависит от регистрации юрлица и расчётного счёта).

## Этапы
**0. Решения (Оля):** название, домен, палитра, логотип, товары; регистрация юрлица и счёт.

**1. Инфраструктура**
- [ ] Копия сайта: аккаунт profcosmetica → Hosting Dashboard → сайт → Settings → Actions → **Duplicate**. Выбрать домен (можно временный `….wordpress.com`), оплатить тариф Business.
- [ ] Сразу после копирования — чек-лист ниже
- [ ] Передать сайт аккаунту нового юрлица (Settings → Danger zone → Transfer), сменить контакты домена
- [ ] Свой домен, когда будет название
- [ ] Репозиторий на GitHub, подключение MCP

**Первые 15 минут после копирования** (копия переносит всё: заказы, клиентов, почту, bePaid, задачи по расписанию — и может работать как настоящий магазин profcosmetica):
1. Настройки → Чтение: запретить индексацию; включить режим «Скоро запуск» / закрытый сайт.
2. WP Mail SMTP: отключить отправку писем (или деактивировать плагин).
3. WooCommerce → Платежи: выключить bePaid и стереть ключи profcosmetica.
4. Code Snippets / WPCode: выключить сниппеты с письмами, фидами и счётчиками (сертификаты `pc-gift-cards`, `prof-gmc-feeds`, `prof-y4ym-feeds`, `prof-gads-conversion`).
5. WP Crontrol: проверить и удалить запланированные письма сертификатов и задачи фидов; Action Scheduler — отменить pending-задачи.
6. Отключить аналитику и пиксели: Site Kit, PixelYourSite, Google Listings & Ads, Яндекс Метрика, фиды XML for Google Merchant Center и Y4YM.
7. Дальше — этап 2 (удалить заказы, клиентов, подписчиков).
