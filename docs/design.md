# Дизайн и палитра

Черновик от 2026-11-25, ещё не утверждён. Исходник — референс, который прислала Оля: [design-reference.png](design-reference.png) (чужой учебный макет таплинка). Берём из него **настроение, палитру и приёмы**. Название, логотип, фото и товары из макета не используем: у нас свои.

## Палитра
Цвета сняты с картинки пипеткой, допустимы небольшие отклонения.

| Роль | Цвет | Где в макете |
|---|---|---|
| Акцент (розовый) | `#F792C3` | кнопки, логотип, лента «sale», иконка корзины |
| Розовый светлый | `#FFC6E5` | плашка «против пластика», фон иконки корзины |
| Голубой пастельный | `#BEDBED` | плашка «только натуральное» |
| Голубой бледный | `#D8F0FC` | бейдж «new» |
| Зелёный пастельный | `#C2E7C5` | плашка «не тестим на животных» |
| Зелёный бледный | `#BDEFBE` | бейдж «sale» |
| Текст основной | `#393939` | заголовки, названия, цены |
| Текст второстепенный | `#767676` | «new», «sale» в заголовках, объём товара |
| Старая цена | `#AAAAAA` | зачёркнутая цена |
| Фон карточек и блоков | `#F7F7F7` | карточки товаров, блок соцсетей |
| Фон страницы | `#FFFFFF` | |

**Доступность.** Белый текст на `#F792C3` читается плохо (контраст около 2:1, норма — 4,5:1). Варианты: тёмный текст `#393939` на розовой кнопке или более насыщенный розовый для кнопок, например `#D6337F` (с белым текстом проходит норму). Решить при настройке темы.

## Приёмы из макета
- Фото — чёрно-белые; цвет дают только розовый акцент и пастельные плашки.
- Кнопки — розовые «пилюли» со скруглением на всю высоту.
- Карточки товаров — светло-серый фон `#F7F7F7`, скругление около 12 px, бейдж «new» / «sale» в углу, розовая квадратная кнопка корзины.
- Заголовки секций — строчные, двухцветные: «новинки **new**», «скидки **sale**» (второе слово серое).
- Плашки-преимущества — «шестерёнки» (волнистые круги) трёх пастельных цветов.
- Розовая волнистая лента с бегущим текстом между секциями.
- Шрифт — гротеск с округлыми формами (похож на Manrope / Montserrat). Подобрать с кириллицей.

## Не решено
- Шрифт, логотип и название.
- Цвет кнопок (см. «Доступность»).
